# Contributing

If you find issues, [report them on GitHub](https://github.com/alexdlaird/shipshape/issues).

If you would like to contribute to the code, the process is pretty simple:

1. Familiarise yourself with the actions, their inputs and outputs in [the README](https://github.com/alexdlaird/shipshape#readme),
   and [GitHub's documentation on composite actions](https://docs.github.com/en/actions/sharing-automations/creating-actions/creating-a-composite-action).
2. Fork [the repository on GitHub](https://github.com/alexdlaird/shipshape) and start implementing changes.
3. Write a test that plainly validates the changes made.
4. Test locally with `make test`.
5. Ensure no linting errors were introduced by running `make check`.
6. Submit a [pull request](https://help.github.com/en/articles/creating-a-pull-request-from-a-fork) to get the changes
   merged.

Also be sure to review the [Code of Conduct](https://github.com/alexdlaird/shipshape?tab=coc-ov-file#contributor-covenant-code-of-conduct)
before submitting issues or pull requests.

Want to contribute financially? If you've found `shipshape` useful, [sponsorship](https://github.com/sponsors/alexdlaird)
would also be greatly appreciated!
